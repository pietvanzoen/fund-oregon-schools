# Analysis index

| File | What it answers |
|---|---|
| `OVERVIEW.md` | Short summary used as the website's home page: key numbers, dates, where to start |
| `BRIEFING.md` | Decision briefing: what's being decided, history (Measures 5 and 50), numbers, positions, proposals, contested claims, next steps, gaps |
| `people/kotek.md` | Kotek's record and statements on school funding and outcomes |
| `people/legislators.csv` | Budget-writing legislators: district, official page, 2025-26 and 2027 roles |
| `people/lieber.md`, `sanchez.md`, `ruiz.md`, `sollman.md` | Ways & Means co-chairs and Education Subcommittee co-chairs |
| `people/quotes_all.jsonl` | Verbatim, dated, cited quotes (`person, role, date, quote, context, cite, confidence`) |
| `promises.csv` | Pledges and mandates: who, when, what, whether money is attached, status |
| `data/ssf_history.csv` | State School Fund by biennium and budget stage |
| `data/qem_gap.csv` | Quality Education Model estimates vs. funding |
| `data/reserves.csv` | Education Stability Fund and other reserves, with conditions for use |
| `derived/<topic>.csv` | Our own calculations (sums, shares, estimates), cited with DER tags; written by `tools/derive_<topic>.py` |
| `topics/reserves.md` | Whether reserves can close gaps |
| `glossary.csv` | Abbreviations and terms in plain words (`term, full_name, kind, tooltip, definition, source`); feeds the Glossary page and the site's hover tooltips |
| `topics/virtual-charters.md` | How State School Fund money follows students to virtual charters; current law and 2025 bills |
| `data/virtual_charters_2025-26.csv` | 2025-26 enrollment (ADMr/ADMw) by virtual charter and sponsor, with sponsor grant rates and an estimate of grant money |
| `timeline.md` | Dated events, past and upcoming |
| `open_questions.md` | Facts to confirm and sources still to find |

Add a `people/<slug>.md` for each legislator who matters (Ways & Means co-chairs, education committee chairs,
Portland delegation) as their statements are archived.
