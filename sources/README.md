# sources/

Primary material only. Never edit, paraphrase into, or overwrite anything here.

- `_queue.csv`: what to fetch. `_manifest.jsonl`: what was fetched (url, final_url, fetched_at, sha256, bytes).
- `_versions_log.csv`: documents that changed upstream; old copies live in `<dir>/_prior/`.
- `news/index.jsonl`: news metadata, own-words summaries and short quotes only.
- Folders: `gov/`, `legislature/olis/`, `legislature/bills/`, `legislature/video/`, `legislature/social/`, `ode/` (incl. `ode/qec/`),
  `fiscal/oea/`, `fiscal/lfo/`, `fiscal/lro/`, `districts/<district>/`, `orgs/<org>/`.
