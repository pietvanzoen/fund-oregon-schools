# Analysis is CC BY 4.0, code is MIT, archived sources are excluded

Status: accepted (2026-11-24, PR #N)

## Context
The repo had no license, so by default nobody could reuse anything in it, which defeats an archive meant to be
cited and built on. It holds three kinds of material: our analysis and site text, our code, and copies of other
publishers' documents in `sources/`, which we can't license.

## Decision
Analysis, data, derived figures and site text are CC BY 4.0. Code is MIT. `sources/` is excluded from both, with a
note that rights stay with the publishers and an email address for removal requests. Terms are in
`LICENSE-content.md`; `LICENSE` holds the MIT text so GitHub detects it.

## Options weighed
- **No license**: keeps every right, but nobody may legally reuse the analysis or code.
- **CC BY 4.0 for content** (chosen): any reuse, including campaigns and news outlets, with credit, which points
  readers back to the cited archive.
- **CC0 for content**: the least friction, but no requirement to credit, so reused figures lose the trail back
  to their sources.
- **CC BY-SA**: anyone mixing our figures into their own material would have to release it under the same terms,
  which puts off most reusers.
- **Any NC (non-commercial) license**: unclear whether a nonprofit newsletter or a newspaper counts as commercial,
  so careful reusers stay away.
- **MIT for code** (chosen) over Apache-2.0 (its patent grant doesn't matter for these scripts) and GPL (copyleft
  buys little for small tools and puts people off).
- **One license for everything**: CC licenses aren't meant for code, and no license can cover `sources/`.

## Revisit when
A publisher objects to a copy in `sources/`, or someone wants to reuse the material under terms these don't allow.
